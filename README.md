# 현장별 집기비품 비용 대시보드

협업부서가 총무팀에 묻지 않고 **현장별 집기비품 집행액을 직접 확인**할 수 있는 웹앱입니다.
서버·데이터베이스 없이 GitHub Pages 만으로 동작하며, 비용은 들지 않습니다.

## 구성

| 파일 | 역할 | 누가 씁니까 |
|---|---|---|
| `index.html` | 조회용 대시보드 | 협업부서 (링크만 공유) |
| `admin.html` | 홈택스 엑셀 업로드 · 현장 분류 · 반영 | 총무팀 담당자 |
| `data.json` | 집행 내역 데이터 (자동 생성) | — |
| `sites.json` | 현장 목록 · 별칭 규칙 · 수동 지정 이력 (자동 생성) | — |
| `config.json` | 데이터 위치 (보통 비워두면 자동 인식) | — |
| `xlsx.full.min.js` | 엑셀 읽기 라이브러리 | — |

동작 방식: **담당자가 admin.html 에서 엑셀 업로드 → data.json 이 GitHub에 저장 → 협업부서는 대시보드 링크만 열면 최신 데이터**

## 반영 속도 — 최대 1분

대시보드는 열려 있는 동안 **60초마다 스스로 데이터를 확인**합니다. 새 데이터가 있으면 화면을 갱신하고 아래쪽에 "새 데이터가 반영되었습니다" 알림을 띄웁니다. 보고 있던 필터·정렬은 유지됩니다.

- 우상단에 `● 자동 동기화 · 방금 확인` 표시가 계속 갱신됩니다. 더 빨리 보려면 `↻ 지금 확인`을 누르면 즉시 반영됩니다.
- 다른 탭에 있다가 돌아오면 그 즉시 한 번 더 확인합니다.
- 데이터는 GitHub Pages 빌드를 기다리지 않고 저장소에서 바로 읽어옵니다. 그래서 커밋 직후 수십 초 안에 반영됩니다.
- 주소가 `https://<아이디>.github.io/<저장소>/` 형태면 위치를 자동으로 알아냅니다. 다른 도메인(회사 도메인, Cloudflare 등)에 올렸다면 `config.json` 만 채워주세요:

```json
{ "owner": "hib1006", "repo": "assets-dashboard", "branch": "main" }
```

## 로그인에 대해

GitHub Pages 는 로그인 기능이 없습니다. 무료 구성에서는 "링크를 아는 사람만 볼 수 있음"이 상한선입니다.
로그인을 꼭 넣으려면 파일은 그대로 두고 **호스팅만 Cloudflare Pages 로 바꾸고 Cloudflare Access 를 켜면** 회사 이메일(`@mooyoungcm.com`)로 인증한 사람만 들어올 수 있습니다. 이것도 무료 범위이고, 아래 "비공개로 쓰려면" 항목에 있습니다.
다만 로그인을 붙이더라도 반영 방식은 위와 동일합니다. 로그인 여부와 데이터 동기화는 별개입니다.

## 최초 설치 (약 10분, 한 번만)

### 1. 저장소 만들기

1. https://github.com/new 접속
2. Repository name: `assets-dashboard` (원하는 이름 가능)
3. **Public** 선택 — Private 저장소는 무료 플랜에서 Pages 가 동작하지 않습니다.
   `data.json` 에 들어가는 내용이 외부에 공개돼도 되는지 먼저 확인하세요.
   공개가 부담스럽다면 아래 "비공개로 쓰려면" 항목을 보세요.
4. **Create repository**

### 2. 파일 올리기

저장소 화면에서 **Add file → Upload files** → zip 안의 파일 전부(`index.html`, `admin.html`, `data.json`, `sites.json`, `config.json`, `xlsx.full.min.js`)를 끌어다 놓고 **Commit changes**.

### 3. GitHub Pages 켜기

1. 저장소 → **Settings** → 왼쪽 **Pages**
2. Source: `Deploy from a branch`
3. Branch: `main` / `/ (root)` → **Save**
4. 1~2분 뒤 주소가 나옵니다:
   `https://<아이디>.github.io/assets-dashboard/`

이 주소를 협업부서에 공유하면 됩니다. 관리자 화면은 `.../admin.html` 입니다.

### 4. 업로드용 토큰 발급

1. https://github.com/settings/personal-access-tokens/new
2. Token name: `dashboard-upload`
3. Expiration: 1년 정도
4. Repository access: **Only select repositories** → 방금 만든 저장소만 선택
5. Permissions → Repository permissions → **Contents: Read and write** (다른 권한은 주지 마세요)
6. **Generate token** → `github_pat_...` 로 시작하는 값 복사

### 5. 관리자 화면 설정

`.../admin.html` 접속 → 1번 칸에 아이디 / 저장소 이름 / `main` / 토큰 입력 → **설정 저장** → **연결 확인**.
토큰은 담당자 브라우저에만 저장되고 GitHub 외 다른 곳으로 전송되지 않습니다.

## 매달 데이터 갱신 (2~3분)

1. 홈택스에서 **매입 전자세금계산서 목록조회** 엑셀 내려받기 (품목 정보 포함으로)
2. `admin.html` 접속 → 엑셀 끌어다 놓기
3. **3번 열 확인** — 자동으로 잡힌 열이 맞는지 훑어보기
   - 무영씨엠 파일 기준으로 현장은 맨 끝 **`품목비고`** 열에서 읽습니다. 이 열 값이 그대로 현장명이 됩니다.
   - `(창원 의창 구청현장)` 처럼 괄호가 있으면 자동으로 벗깁니다.
4. **4번 현장 분류 규칙** — 같은 현장을 여러 이름으로 적은 것만 합치는 단계입니다
   - `자동 후보 찾기` → `품목비고` 에 실제로 들어있는 현장 값들이 목록으로 올라옵니다
   - 합칠 때: 대표 이름 한 줄만 남기고 **키워드 칸에 다른 표기를 쉼표로** 적습니다
     예) 이름 `창원 사파 현장` / 키워드 `창원 사파, 창원사파, 사파동`
   - 아래 표에서 현재 분류 결과(현장별 건수·금액)를 바로 확인할 수 있습니다
5. **5번 미지정 건** — `품목비고` 가 비어 있어 현장을 못 정한 건입니다. 드롭다운으로 직접 지정하세요.
   → 지정 내용은 `sites.json` 에 기록되어 **다음 달에도 자동 적용**됩니다
6. **6번 → 대시보드에 반영** 클릭 → 30초~1분 안에 협업부서 화면에도 반영됩니다

`기존 데이터에 누적` 은 기본 켜져 있습니다(같은 건은 자동 제거). 체크를 풀면 올린 파일로 전체 교체됩니다.

## 자주 막히는 부분

**열을 못 찾는다고 나옵니다**
홈택스 엑셀은 위쪽에 안내 문구가 몇 줄 있어도 자동으로 건너뜁니다. 그래도 실패하면 3번 칸의 드롭다운에서 `일자`·`합계금액`만 직접 골라주세요. 최소 이 두 개만 있으면 동작합니다.

**금액이 두 배로 보입니다**
`합계금액`과 `공급가액`을 같은 열로 잡았을 가능성이 큽니다. 3번 칸에서 분리해 주세요. 대시보드 상단에서 `합계(VAT포함)` / `공급가액` 기준을 바꿔 볼 수 있습니다.

**반영했는데 대시보드가 그대로입니다**
대시보드는 60초마다 자동 확인합니다. 우상단 `↻ 지금 확인`을 누르면 바로 갱신됩니다. `연결 실패`가 계속 뜨면 저장소가 Private 인지, `config.json` 의 저장소 이름이 맞는지 확인하세요.

**현장이 엉뚱하게 묶입니다**
4번의 키워드가 너무 짧아서 다른 현장 이름에도 걸린 경우입니다(예: 키워드 `인천` 이 `인천 청라`, `인천 서구` 를 모두 잡음). 키워드를 길게 쓰고, 규칙 순서가 위에서 아래로 적용되는 점을 이용해 더 구체적인 현장을 위로 올리세요.

**토큰 설정이 어렵습니다**
6번에서 `data.json 내려받기` · `sites.json 내려받기` 를 누른 뒤, 저장소에 직접 Upload 해도 결과는 같습니다.

## 비공개로 쓰려면

- **GitHub Team 이상 유료 플랜**: Private 저장소 + Pages 조합이 가능합니다.
- **Cloudflare Pages (무료)**: 같은 파일을 올리고 Cloudflare Access 로 사내 이메일 도메인만 허용하면, 저장소는 Private 으로 두고 접근 통제까지 됩니다.
- 지금 구성(Public + 링크 공유)은 검색 노출을 막는 `noindex` 만 걸려 있습니다. 주소를 아는 사람은 볼 수 있으니, 거래처명·금액이 외부에 보여도 되는 범위인지 확인하세요.
