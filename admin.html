1저장 위치 (GitHub)

한 번만 입력하면 이 브라우저에 기억됩니다. 토큰은 이 컴퓨터에만 저장되며 전송은 GitHub로만 갑니다.

토큰은 Fine-grained → 해당 저장소만 → Contents: Read and write 권한만 주세요.

2홈택스 엑셀 업로드

전자세금계산서 목록, 신용카드 매입내역 등 .xlsx / .xls / .csv 모두 가능합니다. 여러 개 한꺼번에 올려도 됩니다.

파일을 여기에 끌어다 놓거나

3열(컬럼) 확인

4현장 분류 규칙

현장 이름과, 엑셀 비고·품목에 나타나는 키워드를 적어주세요. 키워드는 쉼표로 여러 개 가능합니다. 위에 있는 규칙이 먼저 적용됩니다.

5현장 미지정 건 직접 지정

규칙으로 못 잡은 건입니다. 여기서 지정한 내용은 다음 업로드에도 그대로 유지됩니다.

일자거래처품목/비고금액현장 지정
