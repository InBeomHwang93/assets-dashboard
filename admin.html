1저장 위치 (GitHub)

한 번만 입력하면 이 브라우저에 기억됩니다. 토큰은 이 컴퓨터에만 저장되며 전송은 GitHub로만 갑니다.

토큰은 Fine-grained → 해당 저장소만 → Contents: Read and write 권한만 주세요.

2홈택스 엑셀 업로드

전자세금계산서 목록, 신용카드 매입내역 등 .xlsx / .xls / .csv 모두 가능합니다. 여러 개 한꺼번에 올려도 됩니다.

파일을 여기에 끌어다 놓거나
현장명이나 정산 상태만 고칠 때 쓰세요. 새 엑셀을 올릴 필요가 없습니다.
